# 云语音服务配置指南

## 一、前置条件

已开通百度智能云的以下服务：

| 服务        | 控制台地址                                                       | 用途    |
| --------- | ----------------------------------------------------------- | ----- |
| 语音识别（ASR） | https://console.bce.baidu.com/ai/#/ai/speech/overview/index | 语音转文字 |
| 语音合成（TTS） | https://console.bce.baidu.com/ai/#/ai/speech/overview/index | 文字转语音 |

## 二、获取凭证

### 2.1 创建应用

1. 登录百度智能云控制台
2. 进入 **语音技术** → **应用管理** → **创建应用**
3. 填写应用名称（如 `VoiceCal`），勾选「语音识别」和「语音合成」
4. 创建成功后获得 **App ID**

### 2.2 获取 API Key 和 Secret Key

在应用详情页可以看到：

| 凭证             | 说明                                  |
| -------------- | ----------------------------------- |
| **App ID**     | 应用唯一标识                              |
| **API Key**    | 接口调用凭证（对应 OAuth2 的 `client_id`）     |
| **Secret Key** | 接口调用凭证（对应 OAuth2 的 `client_secret`） |

### 2.3 免费额度

百度语音服务有免费调用额度：

| 服务        | 免费额度       |
| --------- | ---------- |
| 语音识别（短语音） | 每日 50000 次 |
| 语音合成      | 每日 50000 次 |

## 三、配置项目

### 3.1 修改 application-dev.yml

编辑 `backend/src/main/resources/application-dev.yml`：

```yaml
baidu:
  voice:
    app-id: 你的AppID
    api-key: 你的APIKey
    secret-key: 你的SecretKey
```

### 3.2 验证配置

启动后端后，检查日志中是否有百度 Token 获取成功的日志：

```
百度语音 Token 获取成功
```

如果没有报错，说明凭证配置正确。

## 四、语音处理流程

### 4.1 REST 接口（同步）

| 接口                  | 方法   | 请求体                                    | 说明   |
| ------------------- | ---- | -------------------------------------- | ---- |
| `/api/v1/voice/asr` | POST | `{ audioBase64, format, sampleRate }`  | 语音识别 |
| `/api/v1/voice/tts` | POST | `{ text, voiceType?, speed?, pitch? }` | 语音合成 |

**ASR 请求示例：**

```json
{
  "audioBase64": "<base64编码的音频数据>",
  "format": "pcm",
  "sampleRate": 16000
}
```

**ASR 响应示例：**

```json
{
  "code": 200,
  "data": {
    "text": "明天上午十点开会",
    "confidence": 0.95,
    "durationMs": 1200
  }
}
```

**TTS 请求示例：**

```json
{
  "text": "好的，已为你创建日程",
  "voiceType": "female",
  "speed": 5,
  "pitch": 5
}
```

voiceType 可选值：`female`（女声）、`male`（男声）、`child`（童声）

**TTS 响应示例：**

```json
{
  "code": 200,
  "data": {
    "audioBase64": "<base64编码的MP3音频>",
    "format": "mp3",
    "durationMs": 2400,
    "textLength": 12
  }
}
```

### 4.2 WebSocket 接口（实时）

连接地址：`ws://localhost:8080/ws/voice`

**客户端发送音频：**

```json
{
  "type": "audio_data",
  "sessionId": "s_1234567890_abc",
  "payload": {
    "audioBase64": "<base64编码的音频>",
    "format": "webm",
    "sampleRate": 48000
  }
}
```

**服务端响应：**

```json
// 1. 识别中提示
{ "type": "intermediate_result", "sessionId": "...", "payload": { "text": "识别中...", "isFinal": false } }

// 2. 识别结果
{ "type": "intermediate_result", "sessionId": "...", "payload": { "text": "明天上午十点开会", "isFinal": true } }

// 3. 命令处理结果
{ "type": "final_result", "sessionId": "...", "payload": { "action": "create", "title": "开会", "startTime": "..." } }
```

## 六、常见问题

### Q1: 启动后报 "Token 获取失败"

检查 `api-key` 和 `secret-key` 是否正确，确保没有多余空格。

### Q2: ASR 识别返回空结果

- 确认音频格式与声明一致（PCM/WAV/AMR 格式需 16kHz 16bit 单声道）
- WebM 格式百度 ASR 不直接支持，后端需做格式转换

### Q3: TTS 合成失败

- 文本长度不能超过 500 个汉字
- 检查免费额度是否用完

### Q4: WebSocket 连接后无响应

- 确认后端 WebSocket 端点 `/ws/voice` 已正确注册
- 检查 Vite 代理配置是否包含 `/ws` 路径
