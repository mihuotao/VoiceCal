# 云语音使用文档

## 一、项目使用的云语音服务

本项目（VoiceCal 智能语音日历）使用**百度云**的以下语音服务：

| 服务             | 用途      | 说明                             |
| -------------- | ------- | ------------------------------ |
| **ASR 短语音识别**  | 语音转文字   | 用户语音输入 → 识别为文本 → 解析意图创建日程      |
| **ASR 流式语音识别** | 实时语音转文字 | WebSocket 实时传输，边说边识别，延迟 <500ms |
| **TTS 语音合成**   | 文字转语音播报 | 系统操作结果 → 语音播报反馈给用户             |

### 1.1 ASR 短语音识别

- **API 地址**: `https://vop.baidu.com/server_api`
- **传入格式**: PCM/WAV/AMR/OGG，推荐 PCM 16kHz 16bit 单声道
- **免费额度**: **每日 5 万次**
- **延迟**: 短音频（<60s）识别延迟约 200-500ms
- **场景**: 用户点击结束录音后，上传完整音频进行识别

### 1.2 ASR 流式语音识别

- **API 地址**: `wss://vop.baidu.com/realtime_asr`
- **传输方式**: WebSocket 双向通信
- **帧大小**: 每帧 200ms PCM 音频数据
- **免费额度**: 与短语音识别共享每日 5 万次
- **场景**: 用户说话过程中实时显示中间识别结果（需后端转发百度云流式结果）

### 1.3 TTS 语音合成

- **API 地址**: `https://tsn.baidu.com/text2audio`
- **输出格式**: MP3 音频流
- **免费额度**: 充足（百度未明确限制免费额度）
- **场景**: 日程创建成功后自动播报结果、节日祝福语音播报

## 二、开通百度云语音服务

### 2.1 注册百度云账号

1. 访问 [百度云官网](https://cloud.baidu.com/)
2. 点击右上角"注册"，可使用手机号或百度账号注册
3. 注册完成后登录百度云控制台

### 2.2 创建语音应用

1. 进入控制台后，搜索或找到**人工智能 → 语音技术**
   - 直接访问: [百度语音技术控制台](https://console.bce.baidu.com/ai/#/ai/speech/overview)
2. 点击"创建应用"
3. 填写应用信息：
   - **应用名称**: 例如 `VoiceCal` 或 `智能语音日历`
   - **接口选择**: 勾选 **短语音识别**、**实时语音识别**、**语音合成**
   - **应用描述**: 填写简要说明
4. 创建完成后，在应用列表中查看凭据：

| 凭据字段           | 说明                    | 在项目中的配置项                  |
| -------------- | --------------------- | ------------------------- |
| **AppID**      | 应用的唯一标识               | `baidu.speech.app-id`     |
| **API Key**    | API 访问密钥              | `baidu.speech.api-key`    |
| **Secret Key** | 密钥（用于获取 Access Token） | `baidu.speech.secret-key` |

> **注意**：Secret Key 请妥善保管，不要提交到 git 仓库。

### 2.3 获取 Access Token（自动管理）

项目后端通过 `API Key` + `Secret Key` 自动获取 `Access Token`，无需手动操作。流程如下：

```
BaiduSpeechClient
  └─ getAccessToken()
       ├─ POST https://aip.baidubce.com/oauth/2.0/token
       │   ├─ grant_type=client_credentials
       │   ├─ client_id=${apiKey}
       │   └─ client_secret=${secretKey}
       └─ 返回 access_token（有效期约30天，SDK自动续期）
```

## 三、项目配置

### 3.1 环境变量配置

在 `backend/src/main/resources/application.yml` 中：

```yaml
baidu:
  speech:
    app-id: ${BAIDU_APP_ID}
    api-key: ${BAIDU_API_KEY}
    secret-key: ${BAIDU_SECRET_KEY}

    # 语音识别配置
    asr:
      format: pcm
      sample-rate: 16000
      buffer-size: 200ms

    # 语音合成配置
    tts:
      voice-type: 0    # 0: 女声（度小美） 1: 男声（度小宇） 3: 男声 4: 童声
      speed: 5         # 语速 0-15
      pitch: 5         # 音调 0-15
      volume: 5        # 音量 0-15
```

**实际运行前请配置环境变量**（或直接修改 application.yml 中的值）：

```bash
# Windows PowerShell
$env:BAIDU_APP_ID = "你的AppID"
$env:BAIDU_API_KEY = "你的APIKey"
$env:BAIDU_SECRET_KEY = "你的SecretKey"

# 或在 IntelliJ IDEA 运行配置中设置环境变量
```

### 3.2 各语音功能核心参数说明

**ASR 短语音识别参数**

| 参数        | 值                      | 说明          |
| --------- | ---------------------- | ----------- |
| `format`  | `pcm`                  | 音频格式，推荐 PCM |
| `rate`    | `16000`                | 采样率 16kHz   |
| `channel` | `1`                    | 单声道         |
| `cuid`    | `voice-calendar-{时间戳}` | 用户标识        |

**TTS 语音合成参数**

| 参数    | 值范围      | 说明                      |
| ----- | -------- | ----------------------- |
| `tex` | UTF-8 文本 | 要合成的文本                  |
| `spd` | 0-15     | 语速，默认 5                 |
| `pit` | 0-15     | 音调，默认 5                 |
| `vol` | 0-15     | 音量，默认 5                 |
| `per` | 0/1/3/4  | 发声人：0=女声 1=男声 3=男声 4=童声 |
| `aue` | 3        | 输出格式：3=MP3              |

## 四、项目中的使用方式

### 4.1 整体链路

```
语音交互完整流程：

用户说话
   │
   ▼
前端录音 (MediaRecorder)
   ├── 流式模式（每200ms一帧）──→ WebSocket ──→ 后端 ──→ 百度云流式ASR ──→ 实时中间结果 ──→ 前端显示
   └── 结束录音（完整音频）──→ HTTP POST ──→ 后端 ──→ 百度云短ASR ──→ 最终文本
                                                                          │
                                                                          ▼
                                                                      NLU 意图解析
                                                                          │
                                                                          ▼
                                                                     创建/查询/修改/删除日程
                                                                          │
                                                                          ▼
                                                                   TTS 语音播报结果
```

### 4.2 后端 BaiduSpeechClient

项目后端封装了 `BaiduSpeechClient` 组件，提供三个核心方法：

```java
@Component
public class BaiduSpeechClient {

    // 1. 短语音识别：上传完整音频，返回识别文本
    public String recognizeSpeech(byte[] audioData, String format, int sampleRate)

    // 2. 流式语音识别：建立 WebSocket 连接，实时传输音频帧
    public void startStreamRecognition(WebSocketSession session, String sessionId)

    // 3. 语音合成：文本转语音，返回 MP3 音频字节
    public byte[] synthesizeSpeech(String text, String voiceType, int speed, int pitch)
}
```

### 4.3 后端 VoiceService

`VoiceService` 是语音业务逻辑层，整合 ASR + NLU + 日历服务：

```java
@Service
public class VoiceService {

    // 语音指令全链路处理：ASR → NLU → 执行 → TTS
    public CommandResult processVoiceCommand(byte[] audioData)

    // 流式语音处理
    public void handleStreamAudio(WebSocketSession session, byte[] audioFrame)
}
```

### 4.4 前端录音与语音交互

前端使用 `MediaRecorder` API 采集音频，封装在 `useVoice` composable 中：

| 文件                                       | 说明                       |
| ---------------------------------------- | ------------------------ |
| `src/composables/useVoice.ts`            | 录音、WebSocket 连接、ASR 结果展示 |
| `src/composables/useWebSocket.ts`        | WebSocket 连接管理与消息分发      |
| `src/components/voice/VoiceButton.vue`   | 录音按钮组件                   |
| `src/components/voice/VoiceWaveform.vue` | 语音波形动画组件                 |
| `src/components/voice/VoiceResult.vue`   | 识别结果展示组件                 |
| `src/components/voice/VoiceConfirm.vue`  | 语音操作确认组件                 |

## 五、常见问题

### Q1: Access Token 获取失败

**原因**: API Key 或 Secret Key 配置错误

**解决**: 登录百度云控制台 → 语音技术 → 应用列表，核对凭据是否一致

### Q2: ASR 识别准确率低

**可能原因**:

- 麦克风质量或环境噪音
- 采样率不是 16kHz
- 音频格式不是 PCM 16bit

**解决**: 确保前端录音配置为 `{ sampleRate: 16000, channelCount: 1, sampleSize: 16 }`

### Q3: 流式识别无实时结果

**可能原因**:

- WebSocket 连接未正确建立
- 百度云实时识别接口未勾选

**解决**: 确认应用已勾选"实时语音识别"权限；检查后端 WebSocket 日志

### Q4: 超出免费额度

- ASR 短语音识别：**每日 5 万次**（通常个人开发足够）
- 超限后会返回 `err_no=3304` 错误码
- 可在百度云控制台购买更多配额

### Q5: TTS 返回的不是音频

如果 TTS 返回的是 JSON 而非 MP3 音频，说明请求参数有误。检查 `Content-Type` 是否为 `application/x-www-form-urlencoded`，并确认 `tex` 参数已 URL 编码。
